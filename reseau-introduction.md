1. **Une adresse IP** est un numéro qui identifie un appareil sur un réseau, comme une adresse postale. Elle permet d’envoyer les données au bon destinataire. Exemple : `192.168.1.10`.

2. **Le DNS** est l’annuaire d’Internet : il traduit un nom de domaine, comme `exemple.com`, en adresse IP que les ordinateurs peuvent utiliser pour joindre le serveur.

3. **HTTP et HTTPS** permettent à un navigateur de communiquer avec un site web :
   - **HTTP** transmet les données sans les chiffrer : elles peuvent être lues ou modifiées pendant le trajet.
   - **HTTPS** chiffre les échanges et utilise un certificat pour vérifier l’identité du serveur. Il protège notamment les mots de passe et les informations bancaires.

   Le cadenas HTTPS indique que la connexion est sécurisée, mais ne garantit pas que le site est honnête.:w
