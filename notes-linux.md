Voici 5 commandes Linux de base à essayer dans le terminal.

| Commande | À quoi elle sert |
|---|---|
| `pwd` | Affiche le chemin du dossier actuel. |
| `ls -la` | Liste les fichiers et dossiers, y compris les éléments cachés. |
| `cd ..` | Remonte au dossier parent. |
| `mkdir test` | Crée un dossier nommé `test`. |
| `cat fichier.txt` | Affiche le contenu de `fichier.txt`. |
